# 蜂鸟外卖 - 本地生活配送平台

一个基于 Spring Boot + Vue 的本地生活配送平台，覆盖用户端、商家端、管理端三端。支持智能订单调度、实时配送跟踪、优惠营销等功能。

## ✨ 核心功能

### 用户端
| 功能 | 说明 |
| :--- | :--- |
| 手机号登录 | 微信小程序/手机号一键登录 |
| 商品浏览 | 按分类浏览菜品、套餐 |
| 购物车 | 添加/删除商品，实时计算价格 |
| 下单支付 | 微信支付模拟，订单状态跟踪 |
| 订单管理 | 历史订单、订单状态查询 |
| 地址管理 | 收货地址增删改查 |
| 再来一单 | 快速复购历史订单 |

### 商家端（管理后台）
| 功能 | 说明 |
| :--- | :--- |
| 菜品管理 | 增删改查菜品、套餐 |
| 分类管理 | 菜品分类、套餐分类 |
| 订单管理 | 接单、拒单、派送 |
| 数据统计 | 营业额、销量、用户数据可视化 |

### 管理端
| 功能 | 说明 |
| :--- | :--- |
| 员工管理 | 员工账号、权限管理 |
| 店铺管理 | 营业状态、店铺信息配置 |
| 数据报表 | Excel 导出运营数据 |

## 🛠️ 技术栈

| 模块 | 技术 |
| :--- | :--- |
| 后端框架 | Spring Boot 2.7, MyBatis-Plus |
| 缓存 | Redis（购物车、分布式锁、验证码） |
| 数据库 | MySQL 8.0 |
| 定时任务 | Spring Task（订单超时自动取消） |
| 文件存储 | 阿里云 OSS |
| 前端 | Vue 3, Element Plus |
| 接口测试 | Swagger UI |

## 🚀 快速启动

### 环境要求
- JDK 1.8+
- MySQL 8.0+
- Redis 6.x+
- Maven 3.6+
